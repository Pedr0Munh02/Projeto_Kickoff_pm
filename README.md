♻️ HackCycle

O HackCycle é um projeto desenvolvido para o Hackathon da disciplina de Engenharia de Software I do IFPR por Pedro Munhoz.

O objetivo do projeto é ajudar as pessoas a descobrir como descartar corretamente diferentes tipos de resíduos e encontrar pontos de coleta.

🎯 Funcionalidades

- 🔎 Pesquisar resíduos;
- ♻️ Ver como realizar o descarte correto;
- 📍 Encontrar pontos de coleta;
- 🔍 Filtrar pontos de coleta por tipo de resíduo;
- 📝 Cadastrar e editar resíduos e pontos de coleta.

🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- SQLite

📋 Metodologia

O projeto será desenvolvido individualmente utilizando Kanban para organizar as tarefas.
